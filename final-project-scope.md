# Project 03 Final Project Scope Statement

## Project Purpose

The purpose of this project is to create a two page website about running that provides helpful information for people who are interested in running or want to learn more about the activity in general.

## Project Description

The project will create a two page website focused on running. The homepage will introduce the topic of running and provide basic information about its benefits, beginner tips, and ways to get started. The second page will provide additional information about running, such as preparing for a run, staying consistent, and setting personal goals. Both pages will be connected through navigation and will use the same external CSS stylesheet to create a consistent and organized design.

## Desired Results

* Create a clear and easy to navigate two page running website.
* Provide useful information for people who are new to running or interested in improving their running habits.
* Use HTML to create well structured webpages with headings, paragraphs, lists, and links.
* Use one external CSS stylesheet to create a consistent appearance across both pages.
* Create a website that is visually organized, easy to read, and functional.
* Complete and publish the project in a public GitHub repository.

## Exclusions

The project will not include more than two webpages. It will not include advanced JavaScript features, user accounts, online shopping, or a database. The website will also not include a mobile application or other advanced functionality outside of the required HTML and CSS features.
