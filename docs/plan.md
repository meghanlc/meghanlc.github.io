# Project 03 Project Plan

## Project Overview

The purpose of this project is to create a two page website about running that provides helpful information for people who are interested in getting started with running or who want to learn more about the activity in general.

## Work Breakdown Structure

### 1. Project Planning

* Review project requirements
* Finalize project scope
* Identify project tasks
* Identify potential risks

### 2. Website Development

* Create the homepage (`index.html`)
* Create the second page (`about.html`)
* Create the external stylesheet (`style.css`)
* Add navigation between pages
* Add running related content
* Apply consistent styling

### 3. Testing and Review

* Check that both pages display correctly
* Test navigation links
* Check that the stylesheet works on both pages
* Review content for organization and readability
* Make necessary corrections

### 4. Project Documentation

* Complete `scope.md`
* Complete `plan.md`
* Complete `retrospective.md`
* Create and update `README.md`

### 5. Final Submission

* Publish the website using GitHub Pages
* Verify the live website
* Take screenshots of both pages
* Confirm all project files are in the repository
* Create a ZIP file of the project files
* Submit the required materials

## Task Schedule

## Risk Analysis

The project will use the TAME framework to identify and respond to potential risks.

### Risk 1: Not having enough time to complete the project

* Impact: High
* Probability: Low
* TAME Response: Mitigate

### Risk 2: Having difficulty with HTML or CSS

* Impact: Medium
* Probability: Medium
* TAME Response: Mitigate

### Risk 3: Forgetting a required project document

* Impact: Medium
* Probability: Low
* TAME Response: Avoid

### Risk 4: Website links or pages not working correctly

* Impact: High
* Probability: Low
* TAME Response: Mitigate

## Project Completion

The project will be considered complete when the two page running website is functional and published through GitHub, the required documentation is completed, and all files are organized in the GitHub repository.
