# Project 03 Project Retrospective

## What Went Well

One thing that went well during this project was being able to apply the project management concepts we learned throughout the course to an actual website project. Creating a project scope helped me understand the purpose and boundaries of the website before beginning the development, which was very helpful. I also became more comfortable using GitHub, GitHub Desktop, HTML, and CSS. Building a website about running made the project more interesting because it is a hobby of mine.

## What Went Wrong

One of the biggest challenges was learning how to use some of the technical tools and processes. Since I was new to HTML and web development in general, at the beginning of the course, I sometimes needed extra time to understand how files, folders, GitHub, and CSS worked together. It seemed like a different language to me. I also had to pay attention to making sure the website files were organized correctly and that the pages worked as expected.

## What I Would Do Differently

If I completed a similar project again, I would start planning the website structure and content earlier to have better time management. I would continue using the project management techniques that I've learned because they helped me stay organized and understand what needed to be completed. I would also feel more confident starting the technical portion of the project because I now have more experience with HTML, CSS, GitHub, and GitHub Pages.
